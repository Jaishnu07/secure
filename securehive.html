PROJECT OVERVIEW

Over 80,000 IED-related incidents occurred globally between 2011 and 2021, causing more than 120,000 fatalities. Remote-controlled IEDs can be activated via mobile phones, RF remotes, or walkie-talkies — making traditional detection methods inadequate.

Secure Hive is a compact, cost-effective embedded system that autonomously detects abnormal electromagnetic fields (an indicator of wireless IEDs), blocks wireless activation signals, and notifies authorities in real time.

The system integrates EMF detection, GSM/SMS alerts, GPS tracking, signal jamming, and regenerative recharging into a single deployable unit suitable for vehicles, patrol units, and urban infrastructure.

⚡ Core Innovation

Autonomous threat detection + signal jamming — rare in civilian use — packaged into a prototype under ₹3,500, deployable in police vehicles, military convoys, and public transport fleets.

OPERATIONAL PHASES

1
// Phase 01

DETECTION

EMF detector circuit with TL081 OpAmp identifies abnormal electromagnetic emissions from wireless IED sources within a 1.5–2 meter radius. Signal strength filtering minimizes false positives.

2
// Phase 02

NOTIFICATION

Upon detection, ESP8266 sends email alerts to authorities and SIM800L GSM module sends SMS to vehicle owner with real-time GPS coordinates. Alert dispatch time under 6 seconds.

3
// Phase 03

JAMMING

Custom patch antenna blocks wireless RF communication across key IED frequency bands: 433 MHz, 838 MHz, 1.5 GHz, and 5.8 GHz within a 3–5 meter suppression radius.

4
// Phase 04

RECHARGING

Regenerative braking system harvests kinetic energy to recharge the 12V Li-ion battery, ensuring continuous operation without external power dependency in mobile deployments.

// 03

HARDWARE COMPONENTS

1

EMF Detector

TL081 OpAmp-based circuit calibrated to detect electromagnetic radiation from cellular, Wi-Fi, and Bluetooth signals indicative of wireless IED triggers.

2

Arduino Nano

Main microcontroller coordinating all modules — EMF input processing, GPS data parsing, GSM command execution, and jamming relay control logic.

3

SIM800L GSM

GSM module with external SMA antenna for SMS delivery. Uses AT commands for reliable message dispatch to authorities upon threat detection.

4

ESP8266 NodeMCU

Wi-Fi module integrated with SMTP protocols for email alerts. Provides redundant communication channel alongside GSM for comprehensive notification coverage.

5

NEO-6M GPS

GPS module providing real-time location coordinates with ±5 meter accuracy, integrated with alert systems for precise threat localization and reporting.

6

Patch Jamming Antenna

Custom-designed directional antenna suppressing RF signals in IED activation bands (433 MHz – 5.8 GHz) within a 3–5 meter radius to neutralize remote triggers.
